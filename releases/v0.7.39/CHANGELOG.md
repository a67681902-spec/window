# v0.7.39

- 기존 **지역명 제목 설정창**에 `지역명 2회 (맨 앞 1회 + 제목 안 랜덤 위치 1회)` 체크박스를 추가했습니다. 기본값은 켜짐이며 해제 시 기존 한 번 표시 규칙을 사용합니다.
- 지역명 두 번째 등장은 랜덤 단어와 주제 문구 사이의 다양한 위치에 들어가며, 고정 끝말은 기존처럼 맨 뒤에 유지합니다.
- 지역명이 포함된 랜덤·고정 단어(예: `대구샷시`)를 일괄배포 대상 도시로 현지화하고, 2회 모드에서는 중복된 지역 접두어를 제거합니다. 여전히 3회 이상 검출되면 생성 자체를 중단합니다.
- 지역별 **XLSX 자동 생성**은 기존 제목 생성기의 체크박스 및 저장 슬롯 값을 그대로 사용합니다. 포항시→포항, 칠곡군→칠곡, 대구광역시→대구 규칙 유지.
- 아파트명 제목 모드, 기존 일괄배포 등록·파일 폴더 선택, 플레이스 지사 연결, 티모 사이트의 배포 방식 선택은 변경하지 않습니다.

# v0.7.38

- 신규 캠페인 등록 3단계에서 `autoPublish` 배포 방식 라디오 버튼에 접근하지 않습니다. 현재 사이트의 선택(생성 후 자동배포 포함)을 확인하거나 변경하지 않고 다음 설정으로 진행합니다.
- `E_PUBLISH_DEFAULT`로 등록이 중단되던 검증 및 관련 오류를 제거했습니다.
- 배포 결과와 일괄배포 화면의 설명이 검수 후 배포를 강제한다고 오해하지 않도록, 사이트 선택 유지·미확인으로 수정했습니다.
- 자동실행은 기존처럼 `수동 시작`으로 설정하고, 최종 `[진행]`은 자동으로 누르지 않습니다. 사이트 기본 배포 모드에 따라 게시 동작이 달라질 수 있으므로 실행 전 해당 모드를 직접 확인하세요.

# v0.7.37

- 시·군 인구 8만 명 이상 일괄배포 화면을 추가. 경북 2026년 10월 확정 지역 10곳을 기본 제공하며, 전국은 행정안전부 시·군 인구 CSV를 수동 불러와 갱신하는 방식입니다. 선택한 시·군만 실행합니다.
- 기존 지역명 제목 설정의 랜덤 단어·고정 단어를 재사용해 시·군별 1~100개 제목 XLSX를 독립 생성하고, 포항시→포항·칠곡군→칠곡·대구광역시→대구처럼 제목 표시에서 행정 접미사를 제거합니다.
- 지역이 고정된 제목 접두어(예: 대구샷시)는 현재 시·군 접두어로 바꿉니다. 원래 사용자 제목 설정은 변경하지 않습니다.
- 기존 PC 리소스 이미지 39장, 참고원고, 선택적 헤더/오버레이 폴더를 재사용하며, 도시별 XLSX를 별도 PC 폴더로 백업할 수 있습니다.
- 시·군별 플레이스 지사 선택, 하루 제한(기본 1)/전체 제한(기본 100)과 분리된 도시별 제목 파일 생성, 실행 이력 및 오류 시 중단을 지원합니다.
- 기존 티모의 검수 후 배포·수동 시작 및 [진행] 미실행을 유지합니다. 티모 파일 선택칸 전송 성공은 서버 등록 성공을 의미하지 않습니다. 실제 배포·서버 저장 완료 검증은 티모 UI에서 해야 합니다.
- 경북 외 지역은 공식 CSV 업로드가 필요합니다. CSV 열이 다르면 안내에 따라 재확인하세요. 브라우저 화면을 닫아도 작업을 계속하는 예약 스케줄러는 추가하지 않았습니다.

# v0.7.36

- 배포 설정의 하루 제한과 전체 제한을 각각 독립 입력·저장할 수 있습니다. 제목을 다시 생성해도 저장된 제한값은 유지합니다.
- 자동 등록은 티모 사이트의 기본값인 검수 후 배포를 건드리지 않습니다. 생성 후 자동배포로 변경하는 선택 동작을 제거하고, 기본값이 달라졌을 경우에는 안전하게 중단합니다.

- 제목 생성기의 플레이스 URL 입력칸에 본사 및 8개 지사 총 9개 주소를 선택할 수 있는 목록을 추가했습니다.
- 목록에서 선택하면 기존 URL 입력칸과 배포 설정의 저장 주소에 자동 반영되며, 기존 주소 또는 새 주소 직접 입력도 그대로 지원합니다.
- 기존에 저장된 플레이스 주소가 목록에 있으면 지사명이 자동 선택되고, 목록 외 주소는 '직접 입력'으로 표시됩니다.
