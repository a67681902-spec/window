# v0.7.44 — 티모 등록 확인창 자동 클릭 수정

- 티모의 [저장] 다음에 나오는 '등록하시겠습니까?' 확인창에서 [등록] 버튼을 놓치던 문제를 보완했습니다.
- 확인창의 텍스트가 자식 요소로 나뉘거나 공백·아이콘이 포함되어도 인식합니다.
- [등록] 버튼부터 상위 확인창을 찾고, 같은 창에 '등록하시겠습니까?'와 [취소]가 함께 있을 때만 클릭합니다. 다른 [등록] 버튼은 클릭하지 않습니다.
- 최대 25초 동안 확인창을 탐색하고, 사용자가 먼저 수동 등록해 캠페인 목록으로 이동한 경우에도 다음 단계로 이어집니다.
- 등록 이후 캠페인 ID 대조·자료 업로드·신규 ID의 [진행]과 지역별 일괄 처리 로직은 이전 버전 그대로 유지합니다.
- 실제 티모 사이트에서 end-to-end 등록·발행 성공 여부는 미검증입니다.

# v0.7.43 — 지역별 등록·확인·진행 자동화

- 지역 일괄배포 및 [새배포 전체 자동 등록·진행]은 신규 배포 설정 → [저장] → 등록 확인창 [등록] → 신규 캠페인 ID 확인 → 이미지·원고·제목 파일 선택칸 전송 → 예상된 업로드 확인창 자동 처리 → **동일 ID 캠페인의 [진행]**까지 자동 실행합니다.
- 통합 자동 실행에서 `STAGED`는 내부 중간 단계로만 사용하며, 티모 페이지의 ‘수동 저장’ 안내창은 표시하지 않습니다. 단독 설정 시험은 여전히 저장하지 않습니다.
- 캠페인 이름과 ID가 목록의 정확히 한 행에서 확인되고 해당 행의 [진행]이 활성화된 때만 클릭합니다. 예상된 실행 확인창만 자동 승인하며 다른 확인창·보안 인증·중복 이름 발견 시 해당 작업은 중단합니다.
- 사이트 [진행] 클릭 이후 실행 상태가 확인되지 않으면 한 번 더 클릭하지 않고 불확실한 상태를 알립니다.
- 이전 실패(review)·중단(running) 도시도 다음 일괄배포 때 새 캠페인으로 재등록합니다. 성공(prepared) 도시는 재등록하지 않으며 이전 오류 기록을 남깁니다.
- 개별 도시가 실패하더라도 다른 선택 도시를 계속 처리합니다. 최종 결과에 성공·실패 도시 수와 실패 이유를 표시합니다.
- 캠페인 이름에 초·밀리초를 추가하여 같은 분 내 재시도 시 이름 충돌을 완화합니다.
- **제한:** 파일 선택칸 반영과 티모 서버의 실제 업로드 완료는 별개입니다. 자동 [진행] 후 실제 게시 성공 여부는 티모 서버 상태로 확인해야 합니다.
- 기존 제목 설정·자연스러운 문장형·지역명 2회·마지막 고정 단어·이미지 폴더는 유지하고, 사이트의 ‘검수 후/생성 후 자동배포’ 선택은 읽거나 변경하지 않습니다.

# v0.7.42 — 일괄배포 실패 이력 개선

- 포항 등 이전 실행이 실패 또는 중단된 지역의 이력은 유지하며 자동 재등록하지 않습니다.
- 이전 실패 지역 때문에 다른 모든 도시까지 시작이 차단되는 현상을 개선했습니다. 등록되지 않은 다른 시·군은 명시적인 실행 확인을 받은 후 계속 진행할 수 있습니다.
- [이전 실패 원인 보기] 버튼을 추가하여 브라우저에 보관된 이전 오류 내용과 지역명을 표시합니다.
- [티모 캠페인 목록 열기] 버튼을 추가하여 중복 캠페인을 직접 확인할 수 있습니다.
- 이전 실패 이력 초기화는 종전처럼 선택한 도시와 사용자 확인이 있을 때만 진행합니다. 자동 초기화·자동 중복 등록은 하지 않습니다.
- 배포 방식은 티모 사이트 선택을 유지합니다. 마지막 [진행] 버튼은 누르지 않습니다.

# v0.7.41 — 지역 제목 자연스러운 문장형 생성 모드

- **자연스러운 제목 생성(문장형)** 체크박스를 기존 지역 제목 생성기와 지역 일괄배포 제목 설정에 각각 추가. 기본은 꺼짐으로 이전 제목 조합 방식 유지.

- 기존/일괄배포 화면의 자연스러운 제목 옵션 실시간 양방향 동기화와 설정 저장·복원/슬롯 연동.
- 일괄배포의 [실제 제목 미리보기] 및 XLSX 모두 기존과 같은 빌드 함수를 사용.
- 티모 실제 [진행] 버튼 자동 클릭 없음; 티모 사이트의 배포 방식 확인/변경 없음.
