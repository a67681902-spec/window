# v0.7.27 — 2026-11-03

- 제목과 원고 업로드 주소를 현재 티모의 /references 화면으로 통합하고, 형식과 다중선택 여부로 각각의 입력칸을 구분합니다.
- 원고 허용 확장자를 TXT/DOCX로 맞춥니다. 이전 DOC 파일은 더 이상 선택하지 않습니다.
- 제목·원고 따로 발행을 선택하고 반영 여부를 확인한 뒤 전송합니다.
- 헤더 및 오버레이 폴더·경로·권한을 기존 저장 방식으로 기억합니다.
- 헤더 자동 업로드 선택, 최대 5장 확인, 파일명 숫자 순 정렬, 가로/세로 배치를 추가합니다.
- 투명 PNG 오버레이 자동 업로드와 개별 업로드 버튼을 추가합니다.
- 특성이미지는 기본적으로 사용 안 함입니다. 필요한 폴더를 연결한 뒤 사용으로 선택하세요.
- 기존 캠페인명/ID 확인, 리소스 39장, 제목 생성, 최종 진행 버튼 수동 실행은 유지합니다.

검증: JavaScript 구문 검사 및 10개 모의 업로드 시나리오 통과. 실제 티모 DOM과 구역명·입력 형식·배치 라벨 대조 완료. 실제 파일 업로드/발행 및 사용자 PC 확장 실행은 미검증입니다.

이 폴더는 기존 v0.7.26 확장에 덮어쓰는 업데이트 파일입니다. 신규 설치용 전체 확장이 아닙니다.
