2. 지사/지역·키워드

플레이스 주소는 1. 제목 생성에서 한 번만 입력합니다. 여기에는 같은 주소가 자동 표시됩니다.

제목 생성기에서 지역을 지정하고 제목을 생성해 주세요.

티모 신규 배포 화면에는 별도 '배포지역' 입력칸이 확인되지 않았습니다. 이 지역은 제목 구성과 생성 키워드에 자동 반영됩니다.

제목 생성기에서 제목을 만들면 여기에 자동 반영됩니다.

티모로 자동 전송할 키워드는 제목 생성기에서 선택한 키워드 + 해당 시군구입니다. 별도 추가 키워드를 쓰려면 제목 생성기의 키워드 항목에서 수정하세요.

대출이자

고정 제외어는 우선 생성 키워드에서 검사합니다. 원고 본문 검사와 티모 자체 제외어 설정 연동은 아직 구현 전입니다.

키워드 준비 중
전송할 키워드 목록을 확인하세요.

3. 배포설정 기본값

티모에서는 URL 입력 후 Enter 또는 우측 ✓로 태그 확정해야 저장됩니다. 자동 확정 여부가 확인되지 않으면 프로그램이 중단합니다.

제목 생성 후 중복을 제외한 고유 단지 수를 자동으로 입력합니다. 두 제한값을 동일하게 설정합니다.

자동 시작 대신 수동 시작, 생성 후 즉시배포 대신 검수 후 배포를 기본으로 합니다. 자동 [진행] 실행은 금지합니다.

4. 새 배포 생성 시험

제목 생성기에서 선택한 시군구와 등록 날짜·시간으로 캠페인명을 자동 작성합니다. 플레이스 1개만 시험하며, [신규 캠페인] 선택을 확인한 경우에만 진행합니다. 이번 시험에서는 마지막 [저장]을 누르지 않습니다.

제목 생성 → 플레이스 주소 입력 → 신규 배포 시험 순서로 진행해 주세요.

이번 시험은 마지막 [저장] 버튼을 누르기 직전에 정지합니다. 자동 시작은 수동 시작으로, 배포는 검수 후 배포로 지정합니다. 실제 등록 저장·리소스 이미지 업로드·제목 업로드는 아직 수행하지 않습니다.

5. 자료 등록 · 대상 ID 검증 대기

안전 잠금: 이전 버전은 열린 티모 탭의 ID를 신규 캠페인 ID로 잘못 인식할 수 있었습니다. 생성 직후 저장 결과와 ID를 연결하는 검증이 완료될 때까지 이미지·참고원고·제목 파일 전송을 중단합니다. 현재 이곳에서 어떠한 파일도 올리지 않습니다.

아직 자료 등록을 실행하지 않았습니다.

제목 생성기의 XLSX를 PC에 다운로드하지 않고 내부에 보관합니다. 이미지와 참고원고는 기존에 선택한 폴더의 파일을 사용합니다. 서버 업로드 성공 여부는 티모의 자료 목록에서 확인해야 합니다.

기존 제목 생성기와 자료 폴더 설정은 유지됩니다. 새 캠페인 저장 응답으로 발급된 ID를 확인하는 기능을 구현한 이후, 검증된 신규 배포에만 업로드 시험을 재개합니다.
