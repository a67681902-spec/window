# v0.7.57 — 대구·인천·부산·울산 광역시 인구 집계 오류 수정

- **원인**: 이전 `parsePopulation()` 코드가 광역시 산하 `군`을 일반 `구`와 다르게 처리하고, `출장소`처럼 이름이 읍·면·동으로 끝나지 않는 행을 **광역시 전체 인구 행으로 오인**했습니다. 대구 다사읍서재출장소 37,411명 / 인천 북도면장봉출장소 949명이 잘못된 광역시 총인구가 되어 인구 기준에 미달했습니다.
- **수정**: 광역시의 자치구와 군(郡)을 동일한 하위 행정구역으로 취급합니다. 읍·면·동 및 출장소 행을 `시도+시군구+읍면동`별로 고유하게 합산하고, 광역시 전체는 한 개 캠페인으로 유지합니다.
- CSV에 **광역시 전체 합계 행**이 있으면 이를 우선하고, **시군구 합계 행과 하위 행**이 동시에 존재하면 시군구 합계를 우선해 중복 계산하지 않습니다.
- 사용자 제공 **행정안전부 2026-10-31 인구 CSV**에서 인구 합계: **대구 2,345,185명, 인천 3,070,203명, 부산 3,226,446명, 울산 1,085,888명**(전체 읍면동 행 합계).
- 서울·대전·세종 및 `전남광주통합특별시`의 광주 자치구/전남 시군 분리 기능을 유지합니다.
- 저장된 `timoPopulationImportV1`에는 **이전에 계산된 결과만** 있어, 새 집계 로직을 적용하려면 **최신 버전 설치 후 같은 CSV를 다시 불러와야** 합니다. 과거 파서로 저장된 CSV가 로드되면 화면에 재불러오기 안내를 표시합니다.
- 새로운 CSV 파싱 결과에는 `parserVersion: 2`를 저장합니다. CSV 자료를 다시 불러와도 전국 혼합 선택 지역, 지역별 플레이스 주소, 인구 기준, 배포 수량 및 기존 배포 이력은 삭제하지 않습니다.
- 기존 저장소 키(`timoRegionBatchHistoryV1`, `timoMixedBatchConfigV1`, `timoBatchSettingsV1`, `timoRegionBodyConfigV1`, `timoPopulationImportV1`) 변경 없음.
- 수정된 JS 구문 검사 및 가상 CSV 테스트에서 대구·인천·부산·울산·광주·전남·경북, 광역시/시군구 중복 합계 우선 처리를 검증했습니다.
- 티모 서버에서의 실등록/실발행은 검증하지 않았습니다.

# v0.7.56 — 인구·배포 수량 및 전국 지역 선택·이력 업데이트 후 유지

- 지역 일괄배포의 **최소 인구**, **지역별 제목 개수**, **하루 배포 제한**, **전체 배포 제한**을 `timoBatchSettingsV1`에 각각 자동 저장하고 새 설정 화면에서 복원합니다.
- 기존 시·도별 배포의 지역별 체크 상태와 지사 선택도 시·도별로 별도 저장합니다. 이전에 체크 해제한 지역이 화면을 다시 열었다고 자동 선택되지 않습니다.
- 기존 혼합모드 선택 지역·지사/플레이스 URL은 이미 사용 중인 `timoMixedBatchConfigV1` 키를 그대로 보존하고 복원합니다.
- 인구 기준이 일시적으로 높아져 시·군이 목록에 나타나지 않아도 기존 선택 기록은 삭제하지 않습니다. 기준을 다시 낮추면 이전 선택이 나타납니다.
- 전국 인구 CSV를 다시 불러와도 혼합 선택·지역별 선택을 지우지 않습니다. 기존 CSV 자료 `timoPopulationImportV1`은 그대로 유지됩니다.
- 전국 지역의 기존 캠페인 등록·진행 이력 `timoRegionBatchHistoryV1`은 이동하거나 초기화하지 않습니다. 기존 이력과 재배포 이력은 계속 유지됩니다.
- 새 저장값은 **동일한 크롬 확장 프로그램 ID와 프로필에서 업데이트할 때 유지**됩니다. 확장 프로그램 제거/재설치 또는 다른 프로필로 변경 시 브라우저 로컬 데이터는 이전되지 않을 수 있습니다.
- 이전 시작 확인 지역을 새 양식으로 다시 배포하는 옵션 및 기존 모든 자동화 기능은 유지합니다.
- 실제 크롬 프로필의 설정을 변경하지는 않았으며, 업데이트 설치 후 실제 저장·복원은 사용자 환경에서 확인이 필요합니다.

# v0.7.55 — 이전 완료 지역을 새 양식으로 재배포

- 지역 일괄배포에 **이전 시작 확인 지역도 이번 양식으로 다시 배포 (새 캠페인)** 체크박스를 추가했습니다. 기본값은 체크 해제입니다.
- 체크 시 이전 `prepared` 이력이 있더라도 선택한 지역 전체를 재등록 대상으로 포함하며, 기존 이력을 삭제하지 않습니다.
- 실행 전에 전체 대상·기존 시작 확인·재배포·제외·이번 처리 수를 표시하고, 재배포가 있다면 중복 게시 위험에 대한 추가 확인창을 표시합니다.
- 새 캠페인을 시작하기 전 기존 캠페인 ID/이름/플레이스 주소/시작 상태 등을 이전 실행 기록에 보존합니다.
- 사전 미리보기에서 이전 시작 확인/제외/재배포 지역 수를 구분합니다. 재배포 체크를 하지 않으면 기존의 완료 지역 자동 제외 방식을 유지합니다.
- 이전 완료 이력으로 헤더 이미지 변경 또는 실제 발행 완료를 검증하지 않습니다. 배포 양식 변경 여부는 사용자 판단에 따라 재배포하도록 합니다.
- 다른 자동배포, 지역/광역시 혼합 모드, 플레이스 자동 전환, 키워드/태그/원고 변환 기능은 기존대로 유지합니다.
- 티모 실제 발행 완료는 별도 서버 확인이 필요합니다.

# v0.7.53 — 전국 혼합 일괄배포 및 지역별 플레이스 자동 전환

- 기존 **시·도별 일괄배포**는 그대로 두고, 새 **전국 혼합 일괄배포 · 시군 + 광역시** 모드를 추가했습니다.
- 전국 주민등록인구 CSV를 불러오면 서로 다른 시·도의 시·군과 서울·부산·대구 등 광역시 전체를 함께 선택할 수 있습니다. 광역시는 자치구별 중복 캠페인으로 나누지 않습니다.
- 혼합 선택은 시·도 필터를 변경해도 유지되며, 선택 지역·모드·플레이스 매핑은 Chrome 로컬 설정에 저장됩니다. 수동으로 선택한 지역만 실행하고 자동 전체 선택은 하지 않습니다.
- 기존 9개 플레이스 주소 중 경기·경북·경남·전북·전남·강원·서울·충청의 지사는 해당 시·도에 자동 매칭됩니다.
- 전용 지사가 없는 부산·대구 등은 **지사 직접 선택(본사 포함)** 또는 **네이버 플레이스 URL 직접 입력**을 해야 하며, 주소가 미지정/잘못되면 첫 캠페인을 만들기 전에 중단합니다.
- 캠페인마다 시·도/시·군 이름, 제목 XLSX, 생성 키워드·하단 태그, 원고 지역명, 플레이스 주소를 개별 설정하며 다음 지역으로 자동 진행합니다.
- 동일 이름의 지역(예: 경기 광주시와 광주광역시)은 시·도 키로 구분합니다. 광역시 이름을 캠페인 지역 문맥에 두 번 넣지 않습니다.
- 실행 중 모드·필터 전환을 잠가 캠페인 도중 배포 대상 변경을 방지합니다.
- 기존 단일 시·도 모드, 제목·원고·이미지 기능, URL 생략, 등록 확인 자동 처리, 브라우저 탭 일시 오류 재시도 및 자동배포 흐름은 유지합니다.
- 전국 인구 CSV 파일이 없으면 혼합 배포 실행을 차단합니다. 실제 티모 서버에서 전체 등록/업로드/발행 성공 여부는 실사용 확인이 필요합니다.
