플레이스 배포 자동입력 준비

티모의 플레이스 배포 → 새 배포 설정 화면을 연 상태에서 실행하세요. 화면의 입력칸 이름·종류·위치만 분석합니다.

조회 전용. 로그인 정보, 입력된 주소·원고·비밀번호·쿠키는 저장하지 않습니다. 배포 버튼도 누르지 않습니다.

제목 템플릿 엑셀 등록

기존 티모 방식 그대로 제목 생성기에서 만든 엑셀을 업로드합니다. ‘제목 내 필수 기재될 텍스트’ 설정은 변경하지 않습니다.

티모 제목 템플릿 화면에서 누르세요. 파일 선택 후 티모에 표시된 제목 개수를 확인합니다. 기존 목록 삭제나 배포 실행은 하지 않습니다.
자동배포 연결을 위한 화면 구조를 먼저 확인합니다.
화면 분석 파일은 PC의 다운로드 폴더에 저장됩니다. 저에게 파일을 보내주시면 실제 자동입력을 연결합니다.
