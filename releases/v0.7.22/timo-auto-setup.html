2. 지사/지역·키워드

플레이스 주소는 1. 제목 생성에서 한 번만 입력합니다. 여기에는 같은 주소가 자동 표시됩니다.

제목 생성기에서 지역을 지정하고 제목을 생성해 주세요.

티모 신규 배포 화면에는 별도 '배포지역' 입력칸이 확인되지 않았습니다. 이 지역은 제목 구성에 사용되며, 티모의 생성시 포함할 키워드에는 지역명과 시·군·구만 자동 반영됩니다.

제목 생성기에서 제목을 만들면 여기에 자동 반영됩니다.

체크한 대키워드 묶음의 하부키워드를 합친 뒤 현재 배포지역 키워드를 자동으로 추가합니다. 여러 대키워드를 동시에 선택할 수 있으며, 수정한 묶음은 다음 배포에도 그대로 유지됩니다.

대키워드를 선택하세요

최종 전송: 선택한 하부키워드 → 중복 제거 → 현재 배포지역/시군구 추가. 중구·동구·서구·남구·북구·강서구처럼 여러 도시에 반복되는 구 이름은 지역키워드에서 제외합니다.

대출이자

고정 제외어는 우선 생성 키워드에서 검사합니다. 원고 본문 검사와 티모 자체 제외어 설정 연동은 아직 구현 전입니다.

키워드 준비 중
전송할 키워드 목록을 확인하세요.

3. 배포설정 기본값

기본 5개 주소를 저장해 둡니다. 필요하면 줄을 추가·삭제하거나 다른 URL로 수정할 수 있습니다. 티모에서는 각 URL을 하나씩 태그로 확정하며, 이미 등록된 같은 URL은 다시 추가하지 않습니다.

제목 생성 후 중복 제거가 끝난 최종 제목 개수를 자동으로 입력합니다. 하루 제한과 전체 제한을 같은 값으로 설정합니다.

자동 시작 대신 수동 시작, 생성 후 즉시배포 대신 검수 후 배포를 기본으로 합니다. 자동 [진행] 실행은 금지합니다.

4. 새 배포 생성 시험

제목 생성기에서 선택한 시군구와 등록 날짜·시간으로 캠페인명을 자동 작성합니다. 플레이스 1개만 시험하며, [신규 캠페인] 선택을 확인한 경우에만 진행합니다. 이번 시험에서는 마지막 [저장]을 누르지 않습니다.

제목 생성 → 새배포 한번에 실행 또는 개별 시험 순서로 진행해 주세요.

새배포 한번에 실행: 제목 결과 확인 → 새 배포 설정 입력 → 실제 [저장] → 신규 캠페인 ID 자동확인 → 2초 대기 → 이미지 → 참고원고 → 제목 업로드 순서로 실행합니다. 실제 [진행] 버튼은 누르지 않습니다.

기존 새 배포 1건 자동입력 시험은 그대로 유지되며 마지막 [저장] 직전에 멈춥니다. 아래 이미지·원고·제목 개별 업로드 버튼도 그대로 사용할 수 있습니다.

5. 자료 등록 · 배포 ID 직접 확인 시험

티모에서 방금 저장한 신규 배포의 ID를 직접 확인해 입력하세요. 업로드 직전에 프로그램이 해당 ID 화면의 캠페인명이 최근 생성 캠페인명과 일치하는지 최대 10초 동안 반복 확인합니다.

아직 자료 등록을 실행하지 않았습니다.

제목 생성기의 XLSX를 PC에 다운로드하지 않고 내부에 보관합니다. 이미지와 참고원고는 기존에 선택한 폴더의 파일을 사용합니다. 서버 업로드 성공 여부는 티모의 자료 목록에서 확인해야 합니다.

ID를 잘못 입력하면 다른 배포에 자료가 들어갈 수 있으므로, 티모의 캠페인명과 ID를 먼저 확인하세요. 실제 [진행] 버튼은 자동으로 누르지 않습니다.
