4. 인구 8만 이상 시·군 일괄배포

기존 제목 설정창의 지역명 제목·랜덤 단어·고정 단어와 지역명 2회(맨 앞+랜덤 위치) 옵션을 그대로 불러옵니다. 시·군별 제목 XLSX를 각각 생성하며, 제목에는 포항시→포항, 칠곡군→칠곡처럼 행정 접미사를 제외합니다. 자동 일괄배포에서는 생성 후 자동배포를 선택하고 검증합니다. 자동실행은 수동 시작 후 해당 캠페인의 [진행]을 클릭합니다.

전국 혼합 일괄배포 · 지역 선택

시·도별 선택 목록에서 시·군과 광역시를 함께 체크합니다. 선택한 지역은 시·도를 바꿔도 유지되며, 광역시는 시 전체를 한 캠페인으로 처리합니다. 현재 선택한 곳만 배포합니다.

전국 혼합 모드에서 배포할 지역을 선택하세요.

지역별 네이버 플레이스 주소 자동 매칭

경기·경북·충청 등 기존 지사는 자동 매칭됩니다. 부산·대구 등 기본 지사가 없는 광역시는 반드시 본사나 다른 지사를 직접 선택하거나 플레이스 URL을 입력해야 합니다. 미지정 지역이 있으면 등록을 시작하지 않습니다.

자동 저장: 최소 인구·제목 수·하루/전체 제한·시·도별 선택 지역·전국 혼합 선택·지사 매칭을 브라우저에 저장하고, 업데이트 후 다시 불러옵니다. 과거 캠페인 시작 기록도 유지됩니다. 확장 프로그램을 제거하거나 다른 크롬 프로필로 이동하면 저장값이 이전되지 않을 수 있습니다.

선택된 키워드 묶음에 현재 시·군 이름을 붙여 생성 시 포함될 키워드와 블로그 하단 태그에 같은 목록을 입력합니다. 예: 샷시 → 포항샷시, 그린리모델링 → 포항그린리모델링. 다음 도시로 넘어가면 그 도시 이름으로 다시 생성합니다. 제목·본문 원고 설정은 변경하지 않습니다.

미리보기 지역을 선택하고 태그 미리보기를 눌러 확인하세요.

지역명 결합 후 10자를 초과하면 자동으로 자르지 않고 배포 전에 오류를 표시합니다. 두 입력칸에 독립적인 구·도 이름 키워드를 덧붙이지 않고 동일한 지역명 목록을 사용합니다. 실제 발행글 반영 여부는 티모 게시 결과로 확인해야 합니다.

참고원고 · 지역명/샷시/샤시 횟수 설정

원본 참고원고 TXT는 그대로 유지하고, 도시별 TXT 복사본을 메모리에서 생성해 해당 캠페인에 업로드합니다. 현재 지역명과 [지역명] 표시도 합산하여 원고마다 최소 횟수를 검사합니다.

‘샷시’와 ‘샤시’는 각각 별도로 집계합니다. ‘샷시교체’, ‘샤시교체’ 안에 있는 단어도 횟수에 포함합니다. 0은 기존 원고를 그대로 유지하며 추가하지 않는다는 뜻입니다.

참고원고 폴더를 연결하고 미리보기 지역을 고른 뒤 확인하세요.

TXT 파일만 지역별 자동 변환하며 지역명·샷시·샤시 횟수는 업로드 전 원고마다 검증합니다. 목표가 높아 문장이 부족하면 중단하므로 미리보기를 먼저 확인하세요. DOCX가 섞여 있으면 원본의 서식 손상을 피하기 위해 배포 전에 오류를 표시합니다. DOCX 파일은 TXT로 저장해 폴더에 넣어 주세요. 티모가 참고원고를 바탕으로 본문을 다시 작성하는 경우 실제 발행글의 지역명 횟수는 다를 수 있습니다.

기본 제공: 경북 2026년 10월 주민등록인구 10개 시·군. 전국 혼합 모드는 행정안전부 시·군별 주민등록인구 CSV를 먼저 불러오세요. 광역시는 자치구별로 중복 배포하지 않고 시 전체를 하나의 캠페인으로 처리합니다. 같은 이름의 시·군은 시·도까지 구분합니다. 2026년 10월 CSV의 '전남광주통합특별시' 표기도 자동 인식해 목포·여수·순천 등 시·군은 전남, 광주 자치구는 광주광역시 전체로 분리합니다.

경북 기본 목록을 사용할 수 있습니다. 다른 시·도는 최신 인구 CSV를 먼저 불러오세요.

기본값은 사용 안 함입니다. 체크하면 이전에 시작 확인된 지역도 다시 신규 등록합니다. 기존 캠페인을 수정·삭제하지 않고 이전 캠페인 ID와 실행 이력을 보관합니다. 중복 발행 가능성이 있으므로 확인 후 실행하세요.

일괄배포 대기 · 캠페인 등록 → 자료 전송 → 신규 ID 확인 후 [진행]까지 자동 실행합니다.

브라우저 탭 관리: 전국 일괄배포에서는 전용 작업 탭 1개를 재사용합니다. 정상 처리 탭은 종료하고, 오류 확인용 탭은 최대 2개까지 유지합니다. 사용자가 직접 연 크롬 탭은 닫지 않습니다.

주의: 기존 실행 이력은 실제 게시 완료가 아닌 캠페인 시작 확인 기록입니다. 이전 완료 지역도 재배포 옵션을 체크하면 새 캠페인이 추가되어 중복 발행될 수 있습니다. 이 화면을 닫으면 일괄 처리가 중단될 수 있습니다.

5. 새 배포 생성 시험

제목 생성기에서 선택한 시군구와 등록 날짜·시간으로 캠페인명을 자동 작성합니다. 플레이스 1개만 시험하며, [신규 캠페인] 선택을 확인한 경우에만 진행합니다. 이번 시험에서는 마지막 [저장]을 누르지 않습니다.

제목 생성 → 새배포 한번에 실행 또는 개별 시험 순서로 진행해 주세요.

새배포 한번에 실행: 제목 결과 확인 → 새 배포 설정 입력 → 실제 [저장] → 확인창 [등록] 자동 클릭 → 신규 캠페인 ID 자동확인 → 2초 대기 → 이미지 → 참고원고 → 제목 업로드 순서로 실행합니다. 확인창의 [등록]까지 자동으로 누르며, 신규 캠페인 이름·ID가 확인되면 실제 [진행] 버튼도 누릅니다.

기존 새 배포 1건 자동입력 시험은 그대로 유지되며 마지막 [저장] 직전에 멈춥니다. 아래 이미지·원고·제목 개별 업로드 버튼도 그대로 사용할 수 있습니다.

6. 자료 등록 · 배포 ID 직접 확인 시험

티모에서 방금 저장한 신규 배포의 ID를 직접 확인해 입력하세요. 업로드 직전에 프로그램이 해당 ID 화면의 캠페인명이 최근 생성 캠페인명과 일치하는지 최대 10초 동안 반복 확인합니다.

아직 자료 등록을 실행하지 않았습니다.

제목 생성기의 XLSX를 PC에 다운로드하지 않고 내부에 보관합니다. 이미지와 참고원고는 기존에 선택한 폴더의 파일을 사용합니다. 서버 업로드 성공 여부는 티모의 자료 목록에서 확인해야 합니다.

ID를 잘못 입력하면 다른 배포에 자료가 들어갈 수 있으므로, 티모의 캠페인명과 ID를 먼저 확인하세요. 신규 자동 실행에서는 ID 검증 후 [진행]이 자동 실행됩니다.
