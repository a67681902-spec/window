3. 배포설정 기본값

기본 5개 주소를 저장해 둡니다. 필요하면 줄을 추가·삭제하거나 다른 URL로 수정할 수 있습니다. 티모에서는 각 URL을 하나씩 태그로 확정하며, 이미 등록된 같은 URL은 다시 추가하지 않습니다.

두 발행 제한값을 각각 입력하여 저장할 수 있습니다. 제목 생성·불러오기로 기존 설정이 덮어써지지 않습니다.

자동실행은 수동 시작을 사용합니다. 배포 방식은 티모 사이트의 기본값인 검수 후 배포를 변경하지 않습니다. 생성 후 자동배포는 이 도구에서 사용하지 않으며 자동 [진행]도 실행하지 않습니다.

4. 인구 8만 이상 시·군 일괄배포

기존 제목 설정창의 지역명 제목·랜덤 단어·고정 단어를 그대로 사용합니다. 시·군별 제목 XLSX를 각각 생성하며, 제목에는 포항시→포항, 칠곡군→칠곡처럼 행정 접미사를 제외합니다. 배포 유형은 티모 기본 검수 후 배포·수동 시작을 유지합니다.

기본 제공: 경북 2026년 10월 주민등록인구 10개 시·군. 전국 배포는 행정안전부의 시·군별 주민등록인구 CSV를 불러온 후 실행합니다. 일반구·자치구를 중복 시·군으로 생성하지 않습니다. 같은 이름의 지역은 시·도 정보를 이용해 구분합니다.

경북 기본 목록을 사용할 수 있습니다. 다른 시·도는 최신 인구 CSV를 먼저 불러오세요.
일괄배포 대기 · 새 캠페인 등록과 파일 선택칸 전달까지만 자동 진행하며, 실제 [진행]은 누르지 않습니다.

주의: 일괄 처리 중 이 화면을 닫으면 중단될 수 있습니다. 결과가 불확실한 도시는 중복 등록 방지를 위해 자동 재시도하지 않습니다. 기존 캠페인과 등록 결과를 확인한 후 다시 시작하세요.

5. 새 배포 생성 시험

제목 생성기에서 선택한 시군구와 등록 날짜·시간으로 캠페인명을 자동 작성합니다. 플레이스 1개만 시험하며, [신규 캠페인] 선택을 확인한 경우에만 진행합니다. 이번 시험에서는 마지막 [저장]을 누르지 않습니다.

제목 생성 → 새배포 한번에 실행 또는 개별 시험 순서로 진행해 주세요.

새배포 한번에 실행: 제목 결과 확인 → 새 배포 설정 입력 → 실제 [저장] → 확인창 [등록] 자동 클릭 → 신규 캠페인 ID 자동확인 → 2초 대기 → 이미지 → 참고원고 → 제목 업로드 순서로 실행합니다. 확인창의 [등록]까지 자동으로 누르며, 실제 [진행] 버튼은 누르지 않습니다.

기존 새 배포 1건 자동입력 시험은 그대로 유지되며 마지막 [저장] 직전에 멈춥니다. 아래 이미지·원고·제목 개별 업로드 버튼도 그대로 사용할 수 있습니다.

6. 자료 등록 · 배포 ID 직접 확인 시험

티모에서 방금 저장한 신규 배포의 ID를 직접 확인해 입력하세요. 업로드 직전에 프로그램이 해당 ID 화면의 캠페인명이 최근 생성 캠페인명과 일치하는지 최대 10초 동안 반복 확인합니다.

아직 자료 등록을 실행하지 않았습니다.

제목 생성기의 XLSX를 PC에 다운로드하지 않고 내부에 보관합니다. 이미지와 참고원고는 기존에 선택한 폴더의 파일을 사용합니다. 서버 업로드 성공 여부는 티모의 자료 목록에서 확인해야 합니다.

ID를 잘못 입력하면 다른 배포에 자료가 들어갈 수 있으므로, 티모의 캠페인명과 ID를 먼저 확인하세요. 실제 [진행] 버튼은 자동으로 누르지 않습니다.
